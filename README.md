# Responsive Personal Portfolio Website

A professional and responsive personal portfolio website created using HTML5, CSS3 and JavaScript.

## 📌 Project Overview

This project is a responsive personal portfolio website designed to present:

- Personal introduction
- About section
- Technical skills
- Projects
- Education and experience
- Contact information
- Contact form

The website is designed to work on desktop, tablet and mobile devices.

---

## 🚀 Features

- Responsive design
- Semantic HTML5 structure
- Responsive navigation menu
- Mobile hamburger menu
- Smooth scrolling
- Home section
- About section
- Skills section
- Projects section
- Education and experience timeline
- Contact form
- JavaScript form validation
- Email validation
- Mobile-friendly layout
- GitHub-ready project structure
